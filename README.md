# Морской бой для iPad / iPhone

Готовая браузерная игра для двух игроков на одном устройстве.

## Возможности

- Два игрока на одном iPad или iPhone
- Поочередная расстановка кораблей
- Ручная или случайная расстановка
- Корабли не соприкасаются, включая диагонали
- Защитный экран при передаче устройства
- После попадания игрок стреляет еще раз
- Автоматическое сохранение партии в Safari
- Адаптивный интерфейс под портретную и альбомную ориентацию
- Не требует сервера или базы данных

## Как запустить локально

Просто откройте `index.html` в браузере. Для корректной работы сохранения лучше использовать локальный сервер:

```bash
python3 -m http.server 8000
```

Затем откройте:

```text
http://localhost:8000
```

## Публикация через GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите в корень репозитория файлы:
   - `index.html`
   - `style.css`
   - `app.js`
3. Откройте `Settings` → `Pages`.
4. В разделе `Build and deployment` выберите:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. Сохраните настройки.
6. GitHub выдаст ссылку вида:

```text
https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/
```

## Добавление на экран «Домой» в iPadOS

Откройте ссылку в Safari → нажмите «Поделиться» → «На экран Домой».
