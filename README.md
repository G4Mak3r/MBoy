# «В пути» — офлайн-игры для iPhone и iPad

Первая версия платформы рассчитана на:

- iPad Air 2022;
- iPhone 13 Pro;
- iPhone 15 Pro;
- Safari и запуск с домашнего экрана;
- портретную и альбомную ориентацию;
- полную работу без интернета после первой загрузки.

## Игры

1. Морской бой — два игрока, скрытая расстановка, один выстрел за ход. Основной экран показывает только поле выстрелов. Собственный флот открывается отдельной защищенной кнопкой.
2. Крестики-нолики — два игрока и локальный счет.
3. 2048 — свайпы и экранные стрелки.
4. Сапер — режимы «Открывать» и «Флаг», чтобы не полагаться на долгое нажатие в автобусе.
5. ИП: Режим выживания — кликер, пассивный доход и офлайн-заработок максимум за 8 часов.

## Запуск локально

ES-модули и Service Worker требуют веб-сервер:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`.

## GitHub Pages

1. Загрузите содержимое папки в корень публичного репозитория.
2. Откройте Settings → Pages.
3. Выберите Deploy from a branch → main → /(root).
4. Откройте выданную GitHub ссылку в Safari.
5. Нажмите «Поделиться» → «На экран Домой».
6. Запустите приложение с домашнего экрана и дождитесь надписи «Офлайн-пакет готов».
7. Проверьте повторный запуск в авиарежиме до поездки.

## Хранение данных

Все партии, рекорды, имена и настройки сохраняются локально в `localStorage`. Сервер и регистрация не используются.


## ИП: Режим выживания

Полноценный недельный экономический симулятор: выбор ниши и стратегии, перепродажа и производство, помещения, оборудование, команда, маркетплейсы, мессенджеры, интернет-магазин, опт, документы, маркировка, товарный знак, кредиты, налоги, дебиторская задолженность и случайные кризисные события. Все цифры и правила являются упрощенной игровой моделью.
